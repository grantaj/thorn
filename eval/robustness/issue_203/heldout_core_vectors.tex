The core comprises those vectors $v$ for which $\|Tv\|<1$.
The reference radius has value $R=4$.
A bibliographic aside concerns a different operator.
\begin{theorem}\label{thm:core}
Every core vector remains inside the reference radius after applying $T$.
\end{theorem}
\begin{proof}
For a core vector the norm of $Tv$ is below one, hence below the reference radius.
\end{proof}
