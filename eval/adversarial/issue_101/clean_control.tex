\section{Geometric profiles}

Fix a real number \(0<\rho<1\), and let
\[
I_\rho=[0,\rho].
\]
For each integer \(n\geq 1\), define the response profile
\[
a_n:I_\rho\to\mathbb R,\qquad a_n(x)=x^n.
\]
We say that the profiles are uniformly attenuating on \(I_\rho\) if for every
\(\varepsilon>0\) there is an integer \(N\) such that
\[
  |a_n(x)|<\varepsilon
  \qquad\text{for every }x\in I_\rho\text{ and every }n\geq N.
\]

The next elementary observation records the decay seen at any fixed
observation point.

\begin{lemma}[Pointwise decay]\label{lem:pointwise}
For every \(x\in I_\rho\) and every \(\varepsilon>0\), there is an integer
\(N_x\) such that
\[
  x^n<\varepsilon\qquad\text{for every }n\geq N_x.
\]
\end{lemma}

\begin{proof}
If \(x=0\) the assertion is immediate.  If \(0<x\leq\rho<1\), then
\(\log x<0\).  Choose \(N_x\) so large that \(N_x\log x<\log\varepsilon\).
For \(n\geq N_x\) we then have
\[
  x^n=\exp(n\log x)\leq \exp(N_x\log x)<\varepsilon.
\]
\end{proof}

\section{Uniform attenuation}

\begin{theorem}\label{thm:uniform-decay}
The geometric response profiles \((a_n)\) are uniformly attenuating on
\(I_\rho\).
\end{theorem}

\begin{proof}
Fix \(\varepsilon>0\).  By Lemma~\ref{lem:pointwise}, for each \(x\in I_\rho\)
choose \(N_x\) with \(x^{N_x}<\varepsilon\).  Continuity of
\(y\mapsto y^{N_x}\) gives an open neighbourhood \(U_x\) of \(x\) in
\(I_\rho\) such that
\[
  y^{N_x}<\varepsilon\qquad (y\in U_x).
\]
The sets \(U_x\) cover \(I_\rho\).  Since \(I_\rho\) is a compact interval,
choose a finite subcover
\[
  I_\rho=U_{x_1}\cup\cdots\cup U_{x_m}.
\]
Set \(N=\max_j N_{x_j}\).  If \(y\in I_\rho\), choose \(j\) with
\(y\in U_{x_j}\).  For every \(n\geq N\), using \(0\leq y\leq\rho<1\),
\[
  y^n\leq y^{N_{x_j}}<\varepsilon.
\]
Thus the defining uniform estimate holds.
\end{proof}
